***Калькулятор в обратной польской нотации
(Reverse Polish notation - RPN)***

Считает выражения в обратной польской нотации.

Позволяет использовать скобки (в них должно быть корректное выражение RPN).

Обрабатывает унарные +/- ($/~). Допускается 1 унарный знак перед числом или скобкой или его отсутствие.

**Поддерживает**:

    целые числа (5)
    числа с плавающей точкой (5.0(преобразуется в целое), 5.5)
    экспоненциальную форму записи числа (5e5 = 5 * 10**5)
	число Эйлера (E = 2.71...)
	число Пи (π = 3.14...)


**Поддерживает операции**:

	"+" - сложение. a b + = a + b
	"-" - вычитание. a b - = a - b
	"/" - деление. a b / = a / b
	"*" - умножение. a b * = a * b
	"**" - возведение в степень. a b ** = a ** b
	"//" - целочисленное деление (только для целых). a b // = a // b
	"%" - остаток от деления (только для целых). a b % = a % b.
